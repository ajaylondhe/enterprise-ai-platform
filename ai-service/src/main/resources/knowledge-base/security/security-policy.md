# Information Security Policy

## Password Security

Employees must use strong passwords for company systems.

Passwords must not be shared with colleagues or external parties.

## Authentication

Company applications may require authentication using approved identity and access management mechanisms.

Employees must protect authentication credentials and access tokens.

## Sensitive Information

The following information should be treated as sensitive:

- Employee personal information
- Customer information
- Financial information
- Authentication credentials
- API keys
- Internal system configuration
- Confidential business documents

## API Keys

API keys and other credentials must never be committed to source control.

Credentials should be stored using approved secret-management mechanisms.

## Security Incidents

Suspected security incidents should be reported to the appropriate security or IT team as soon as possible.

## AI Assistant Security

The AI assistant must not reveal confidential information unless the requesting user is authorized to access that information.
